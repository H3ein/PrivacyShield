# Changelog

All notable changes to PrivacyShield will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.1.0] - 2026-02-12

### Added
- Expanded blocking coverage with additional tracker and ad patterns
- Improved URL matching for better accuracy
- GitHub issue templates for bug reports and feature requests
- GitHub pull request template
- GitHub Actions workflow for automated testing
- Security policy (SECURITY.md)
- Comprehensive CHANGELOG

### Changed
- Modernized UI components for better responsiveness
- Cleaned up constants and improved code organization
- Enhanced content script performance
- Updated README with accurate rule counts and architecture details

### Fixed
- URL matching logic for more reliable blocking
- Bug fixes in content script and background service worker
- Configuration migration issues

### Security
- Removed fake metrics and test data
- Added real malware blocking rules
- Improved input validation

## [3.0.0] - 2025-01-08

### Added
- Production-ready release
- Complete test suite with Jest
- Build system for production packages
- Comprehensive documentation

### Changed
- Complete extension overhaul
- Migrated to Manifest V3
- Brutalist UI redesign

### Removed
- Development and private files from repository
- AI features (moved to monitoring only)
- Legacy code and unused dependencies

See git history for changes before v3.0.0.
