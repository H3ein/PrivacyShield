Click the button below to open the PrivacyShield popup in a new window.

Test Whitelist Functionality

To test the trust site button:

  1. Install the extension in Chrome
  2. Navigate to any website (not chrome:// pages)
  3. Click the PrivacyShield extension icon
  4. Click the "TRUST SITE" button
  5. Button should change to "TRUSTED" and turn orange
  6. Click again to remove from whitelist

Debug Console

Open Chrome DevTools and check the console for:

  • "PrivacyShield: Toggling whitelist for domain: example.com"
  • "PrivacyShield: Added to whitelist: example.com"
  • Any error messages if something fails
