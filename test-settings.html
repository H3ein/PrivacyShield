Manual Test Steps

  1. Install Extension - Load PrivacyShield in Chrome
  2. Open Settings - Right-click extension icon → Options
  3. Add Domains - Add domains to whitelist textarea
  4. Save Whitelist - Click "SAVE WHITELIST" button
  5. Verify Count - Check domain count updates
  6. Test Popup - Visit a whitelisted domain and check popup
  7. Check Storage - Verify domains are saved in Chrome storage

Debug Console Checks

Open Chrome DevTools and look for:

  • "PrivacyShield: Saving whitelist domains: [...]"
  • "PrivacyShield: Added to whitelist: example.com"
  • Storage update success messages
  • No "Unknown setting key" warnings
